# Прогнозирование стоимости недвижимости

Итоговый учебный Data Science проект. На основании истории объявлений строится
модель, которая оценивает стоимость жилой недвижимости в США.

## Цель и задачи

Цель проекта — подготовить прототип модели для агентства недвижимости, который
позволяет получить ориентировочную стоимость объекта по его характеристикам.

Для достижения цели необходимо:

1. изучить и очистить исходные данные;
2. провести разведочный и статистический анализ;
3. подготовить признаки без утечки целевой переменной;
4. построить baseline и несколько ML-моделей;
5. сравнить модели по MAE, RMSE и R²;
6. провести подбор гиперпараметров с групповой кросс-валидацией;
7. сохранить итоговую модель, проанализировать ошибки и сделать приложение.

## Данные

Исходный датасет выдан в рамках учебного курса и содержит 377 185 объявлений и
18 столбцов. Целевая переменная `target` — стоимость объекта. Среди признаков:
площадь, количество комнат и ванных, тип недвижимости, штат, город, почтовый
индекс, год постройки, отопление, парковка и другие характеристики.

Исходный архив не публикуется в репозитории из-за размера. Для воспроизведения
его необходимо поместить в корень проекта под именем `data.csv.zip`; внутри
архива должен находиться файл `data.csv`.

## Этапы работы

1. Выполнен аудит форматов, пропусков и дублей.
2. Удалены аренда, земельные участки, некорректные цены и полные дубли.
3. Очищены цена, площадь, комнаты и этажность; разобран столбец `homeFacts`.
4. Проведены EDA, визуализация и статистические тесты.
5. Данные разделены на train/test по адресу, чтобы один объект не оказался в
   обеих выборках.
6. Обучены медианный baseline и три модели: Ridge, Random Forest и
   HistGradientBoosting.
7. Для бустинга проведён подбор гиперпараметров на train с `GroupKFold`.
8. Выполнен анализ ошибок итоговой модели по ценовым сегментам.
9. Создано локальное Streamlit-приложение для расчёта стоимости.

Поле `Price/sqft` не используется: оно вычислено с помощью цены и создаёт
утечку целевой переменной. Пропуски заполняются внутри ML-pipeline только по
обучающей выборке.

## Статистический анализ

- Корреляция Спирмена между площадью и ценой составляет 0,549 (`p < 0,001`).
  Площадь оставлена среди признаков модели.
- Критерий Краскела — Уоллиса подтвердил различия цен между наиболее
  представленными штатами (`H = 47 067`, `p < 0,001`, `ε² = 0,158`). Поэтому
  географические признаки также используются при обучении.

## Результаты

Основная метрика — MAE, поскольку она легко интерпретируется в долларах и менее
чувствительна к отдельным дорогим объектам, чем RMSE.

| Модель | MAE | RMSE | R² |
|---|---:|---:|---:|
| Медианный baseline | 383 788 | 909 568 | -0,079 |
| Ridge | 212 161 | 590 570 | 0,545 |
| Random Forest | 189 894 | 547 056 | 0,610 |
| HistGradientBoosting | **189 397** | **539 233** | **0,621** |
| HistGradientBoosting после подбора | 191 839 | 548 621 | 0,608 |

HistGradientBoosting выбран итоговой моделью. Его MAE примерно на 50% ниже
медианного baseline. Подбор параметров не улучшил test-метрики, поэтому в
production сохранена более простая базовая конфигурация. Это показывает, что
подбор параметров не обязательно гарантирует улучшение на новых данных.

Медианная абсолютная ошибка составляет 62 020 долларов.
Для объектов дороже 1 млн долларов качество снижается, поэтому результат следует
рассматривать как ориентировочную, а не профессиональную оценку.

```text
├── notebooks/01_eda.ipynb       # очистка, EDA и статистический анализ

├── reports/                     # графики анализа
├── models/                      # обученные модели и метрики
├── scripts/                     # воспроизводимая сборка modeling-ноутбука
├── src/data.py                  # загрузка и очистка

├── src/evaluate.py              # анализ ошибок
```

## Запуск

Проект проверен на Python 3.11.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt

python -m src.eda
python -m src.train
python -m src.evaluate
```

Ноутбуки уже содержат сохранённые результаты выполнения. При необходимости
ноутбук обучения можно полностью пересобрать и выполнить командой:

```powershell
python scripts/build_modeling_notebook.py
```

Итоговая модель находится в `models/final_model.joblib`. Для запуска локального
сервиса:

```powershell
streamlit run app.py
```

После заполнения формы приложение применяет тот же preprocessing pipeline,
который использовался при обучении, и выводит ориентировочную стоимость дома.
